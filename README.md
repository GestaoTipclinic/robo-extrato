# Robô de Extrato — TipClinic

Suplemento do Excel que lê extratos bancários (PDF, Excel, CSV ou OFX) e lança automaticamente na planilha de conciliação da TipClinic, no mês certo, com categoria e divisão entre médicos.

**Uso (sem instalar nada):** na planilha, aba IMPORTAR EXTRATO, botão **① INSERIR EXTRATO** → abre [inserir.html](https://gestaotipclinic.github.io/robo-extrato/inserir.html). Envie o arquivo do banco, clique em Copiar e cole na planilha com **② IR P/ LINHA VAZIA** + Ctrl+V.

Opcional (equipe interna): botão dentro do Excel via suplemento — [instalar.html](https://gestaotipclinic.github.io/robo-extrato/instalar.html).

O extrato é lido no computador de quem usa e vai direto para a planilha; nenhum dado é enviado para servidores.
